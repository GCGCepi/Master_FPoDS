# Student submission format

Use the starter files supplied for each task and keep the required filenames unchanged.

## Files

Each task has two pages:

- `taskXX.html` — your visualisation or task result.
- `taskXX-explanation.html` — your short explanation.

For example, Task 1 uses `task01.html` and `task01-explanation.html`.

## Visualisation page

- Use the supplied starter page and keep the supplied `assets` folder in place.
- Keep the main visualisation inside the reference area of **800 × 450 px**.
- You may include one or more charts or other visual elements, depending on the task instructions.
- Do not rename the required file.

## Explanation page

- Use the supplied explanation page.
- Write **200–300 words**.
- Keep the required filename unchanged.

## Publishing

Publish both files in your group GitHub Pages site so that they can be opened directly by URL.

Your group name will be one of: `group1`, `group2`, …, `group10`.
