# Slides

The class slides ("What is ETL? (notebook version)") are a 11-slide deck of about 10 minutes, with speaker notes on every slide:

1. Cover
2. Real data does not arrive clean (a real excerpt of the Eurostat file)
3. ETL has three phases (Extract, Transform, Load)
4. Extract: data comes from many places
5. Transform: this is where the decisions are
6. Load: the result must go somewhere useful
7. One cell, five columns (before and after)
8. A DataFrame is a table with types and labels
9. How we will work today: read, run, try
10. Session plan
11. Write your prediction (the exercise that closes in Part 5)

The deck is published as a private Slides artifact; use *Share → Export* in the Slides page to download it as PowerPoint or PDF, and keep that file in this folder if you want it versioned with the project.
