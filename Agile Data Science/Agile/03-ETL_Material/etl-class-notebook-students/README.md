# ETL Class: from Raw Data to Useful Data

A **2-hour hands-on class** on **ETL** (Extract, Transform, Load) using real Eurostat data on public spending on education (% of GDP). Students work in a single guided **Jupyter notebook**: they read code, run it, fill small gaps and check their own answers.

Designed for science students (physics, mathematics…) with **no prior Python experience**. No AI agent is used in this version.

## What students learn

- What ETL is and what happens in each phase.
- What a DataFrame is, and the core pandas operations: select, filter, melt, join, group, pivot, rank.
- Why real data is "dirty", and that cleaning it means taking **decisions** (e.g. missing values).
- How to check a result: cross-checks, range checks, duplicates, silent conversion errors.
- How to save results (CSV, Parquet, SQLite) and chart them clearly.
- (Part 6, optional) How to apply it all on a new dataset: merge three tables, filter, pivot, sort and write a small function.

## Requirements

- macOS, Windows or Linux computer with 4 GB of RAM.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) (installs Python and the libraries).
- An internet connection is only needed for the optional download step and for **Part 6**, which downloads MovieLens 1M (about 6 MB) the first time. Parts 0–5 work offline with the files in `data/raw/`. To use Part 6 offline, download [ml-1m.zip](https://grouplens.org/datasets/movielens/1m/) once and unzip it into `data/downloads/` so that `data/downloads/ml-1m/ratings.dat` exists.

```bash
uv sync                           # install the dependencies (once)
uv run jupyter lab notebooks/etl_class.ipynb
```

Prefer VS Code? Open `notebooks/etl_class.ipynb` and select the `.venv` created by `uv sync` as the kernel.

## Schedule (2 hours)

| Time | Block | Content |
|---|---|---|
| 0–15 min | **Slides** + Part 0 | ETL concept; students write their prediction; start the notebook |
| 15–30 min | Part 1 | DataFrames in ten minutes |
| 30–50 min | Part 2 · **Extract** | Look at the files as text, read CSV and TSV, inspect |
| 50–90 min | Part 3 · **Transform** | Melt, split value/flag, join, aggregates, **missing-value vote**, group, pivot, rank, checks, **bug hunt** |
| 90–110 min | Part 4 · **Load** | Save to CSV/Parquet/SQLite, read back, charts, one-command pipeline |
| 110–120 min | Part 5 | Reflection and wrap-up |
| Extra (about 45 min) | Part 6 · **Hands on** | Optional homework: the original exercise sheet on films and ratings (MovieLens 1M), in small guided steps |

## Project layout

```
notebooks/etl_class.ipynb        Student notebook (exercises with gaps and checks)
etl/                             Helper package: the same steps as reusable functions
  extract.py  transform.py  load.py  pipeline.py  movielens.py
data/raw/                        Raw Eurostat files (unchanged)
data/reference/geo_codes.csv     Country code -> name lookup table
data/exercises/                  File with planted errors (bug hunt)
data/downloads/                  Where the optional downloads go (Eurostat, MovieLens 1M)
data/processed/  output/         Generated by the notebook (git-ignored)
instructor/                      Solutions notebook, guide, error key, notebook builder
slides/                          Notes on the slides
```

Run the whole pipeline without the notebook:

```bash
uv run python -m etl.pipeline
```
